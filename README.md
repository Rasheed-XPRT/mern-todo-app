# 📝 MERN Todo App

A full-stack Todo application built with the MERN Stack.

## Features

- Create tasks
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks
- Dark mode
- Responsive design
- Toast notifications

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Axios

## Installation

```bash
npm install
npm run dev
```
